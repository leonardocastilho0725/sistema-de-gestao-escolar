# 🏫 Nexus Acadêmico - Sistema de Gestão Escolar

O **Nexus Acadêmico** é um sistema de gerenciamento escolar desenvolvido em Python que roda diretamente no terminal. O projeto foi criado com o objetivo de consolidar conceitos fundamentais de lógica de programação e manipulação de estruturas de dados em memória.

---

## 💡 Funcionalidades

- **Cadastro de Alunos**: Permite adicionar nome, idade e série em um fluxo contínuo.
- **Remoção de Alunos**: Busca pelo nome para remoção da lista.
- **Cadastro de Funcionários**: Registro rápido de colaboradores do quadro ativo.
- **Remoção de Funcionários**: Exclusão de membros da equipe.
- **Visualização de Relatórios**: Exibição dos cadastros de alunos e funcionários ativos.

---

## 🛠️ Conceitos Praticados

- **Estruturas de Dados**: Uso de dicionários para estruturar dados e listas para armazenar os registros.
- **Loops de Repetição**: Uso de `while` geral para o menu e loops `while` internos para cadastros contínuos, além de laços `for` para percorrer as coleções.
